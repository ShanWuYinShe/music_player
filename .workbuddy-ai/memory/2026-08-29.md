## 第三轮：fractal 重写（用户反馈"闪一下+平移，看不出在变近"）

- 用户看到的现象对上了磁盘上那版"八度流"的毛病：参数用**整数八度序号 k**
  取值（`off = ...sin(k*1.93)`），每个像素的 k 约每 2 秒 +1 → 参数阶跃 →
  画面"闪一下然后平移一点"；`sym` 非整数还在角向留了一道 mod 缝。
  另缺"每八度旋转对齐"（映射 T 的自相似变换自带旋转 θ，不补上环与环接不上）。
- 重写为**对数极坐标 + 周期 Julia 逃逸时间**：
  lr = −log2(ρ) + D（D=深潜八度数，连续），fN = fract(lr/NOCT)；
  Julia 初值沿闭合曲线 z0 = ring(θ) + (a−0.5)·tang(θ) 取，θ=TAU·fN
  → 图案沿八度方向**严格周期**，放大 S 倍后自然接续：无绕接、无闪烁、无精度上限。
  着色用平滑逃逸计数 sm 的等值丝 + 轨道陷阱 + 周期值噪声（频率取整数才不破周期）。
- 为能量化用户反馈，新增两个脚本（都在 binaries/node/workspace）：
  - `shader_flow.mjs`：先重采样成对数极坐标（行=−log2 r，列=角度）再做二维位移
    匹配 → 行位移=径向流速（八度/秒）；顺带测逐帧亮度突变判闪烁。
    **踩坑**：整幅图缩放匹配会被静态径向包络（中心辉光/暗角）带偏；
    角度平均后的径向剖面会被多重对称抹平——都会误报 0。
  - `shader_stability.mjs`：扫 12 个时间点的亮度，看周期性起伏。
- 调优过程（全部以数字为准）：
  - 首版过曝 lum 0.30/sat 0.19：几项"铺满全屏的加法"叠加 → 纹理改**调制**。
  - 发现 `inside = 1 − sm/12` 含义写反（sm=12 才是集内），等于给外围铺雾 → 改 deep。
  - 亮度随深度起伏 4.2×：NOCT 取 10 而屏幕只跨 5~6 个八度，窗口滑过时
    "集内面积"占比周期变化 → **NOCT 改成 6（对齐屏幕跨度）**，起伏降到 1.65×。
  - 环半径推太远（1.30）导致过暗 → 收回 1.16，增益 1.70 + gamma 0.70 抬暗部。
- 最终结果：闪烁中位 0.010/最大 0.139（阈值 0.15）✓；
  径向光流 0.60 八度/秒（设计值 0.58，样本高度一致）✓；
  亮度 0.113~0.187 起伏 1.65× ✓；四 preset 全部编译成功 29fps；
  bun test 26/26、build、lint 全绿；端侧生成头 + 桩编译通过。
