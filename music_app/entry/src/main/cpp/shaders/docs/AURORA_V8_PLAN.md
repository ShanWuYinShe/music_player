# aurora v8 改进方案 —— 基于实拍照片的差距分析与重构路径

参考：4 张实拍极光照片（雪山 S 弧 / 冰岛爆发冠冕 / 峡湾涡旋 / 森林射线弧带）。
当前实现：`aurora.frag` v7.1（抛物线拱薄弧带 + 底缘断崖 + 山脊剪影）。

---

## 一、照片关键视觉特征分析

### 1.1 色彩分布（四张照片共性 + 差异）

| 层位 | 颜色 | 物理来源 | 出现照片 |
|------|------|----------|----------|
| 底缘亮线 | **白绿**（最亮处接近白） | 最强发射 + 传感器饱和 | 全部 |
| 带内主体 | **黄绿 557.7nm** | 氧原子 100~150km 发射 | 全部 |
| 带内上部 | **黄→橙渐变** | 发射减弱 + 高层氧红混入 | 图1/3/4 |
| 带顶 | **紫红→蓝紫** | 630nm 氧红 + N2+ 427nm | 图1/2/4 |
| 爆发区 | **品红/粉红主导** | N2/N2+ 强电离（substorm） | 图2 |
| 涡旋芯 | **白色** | 亮度峰值饱和 | 图3 |

关键结论：**颜色是"沿带高度 + 活跃度"的双变量函数**——同一时刻，底缘白绿、
主体黄绿、顶部紫红；爆发（act 高）时品红整体入侵。v7.1 的"底绿→中青→顶红"
单调渐变少了"白芯"和"品红爆发"两个层次。

### 1.2 光带形态（四种签名形态）

1. **S 形大弧**（图1、图3）：整条弧带是一条大尺度 S 弯（波长 ≈ 1 屏宽），
   不是对称抛物线。v7.1 用 ARC_K 抛物线 + ARC_GAIN 0.12 fbm——太对称、太规则。
2. **涡旋/curl**（图3 中央）：弧带局部打结旋转，是实拍极光最有生命感的形态，
   v7.1 **完全没有**。
3. **竖直褶皱（drape fold）**（图4）：沿弧带分布的竖向折叠，波长 ~0.1 屏宽，
   底缘呈波浪。v7.1 WOB=0.030 幅度过小（v6 曾 0.115 被判"布料窗帘"回撤——
   但照片证明褶皱是真实存在的，只是要"竖直方向"而不是"整体摇曳"）。
4. **爆发冠冕 corona**（图2）：射线从天顶向外放射，带内色序重排（品红主导）。
   v7.1 的 act 只影响亮度，不影响几何与色序。

### 1.3 射线结构（与帘体的关系）

照片里射线是**独立的结构**：从底缘向上贯穿整条带（图4 中射线甚至穿过带顶
延伸到暗天空），亮度可以比周围帘体高 2~3 倍，且**沿弧带快速左右扫动**（视频
里射线"跳舞"）。v7.1 的射线是帘体内部的纹理调制（rays/hero/needles 都乘在
body 上），永远无法比帘体本身亮出层次。

### 1.4 明暗对比与动态

- **暗天空占主导**（照片里极光约占画面 30~50%，v7.1 的薄带策略正确，保持）。
- **亮度非均匀**：亮段/暗段交替明显（presence 断点），亮段内还有更亮的"英雄段"。
- **动态语言**（从视频经验补充）：射线扫动、褶皱沿带传播、底缘"蛇行"、
  亮度波从一端涌向另一端（surge 应该是**空间传播的波**，不是随机闪）。

### 1.5 背景细节

- 星空：小而锐利，顶部密（v7.1 已有 3 层，够用）。
- 银河：隐约，不能抢戏（v7.1 MW_GAIN=0.30 正确）。
- 地景：山脊/树剪影近黑；**雪地/水面被极光染色**（图4 雪地泛绿、图2/3 水面
  倒影）。v7.1 只有山脊上缘的"绿色上光"，缺**地平线整体低空辉光**（雪原
  被极光整体照亮的观感）。

## 二、当前实现（v7.1）差距清单

| # | 差距 | 照片证据 | 影响 |
|---|------|----------|------|
| G1 | 带内色阶缺"白芯"与"上部紫红过渡" | 图1/3/4 | 色彩单薄，像"贴图"不像"发光体" |
| G2 | 爆发时缺品红主导模式 | 图2 | substorm 只有亮度变化，没有色变 |
| G3 | 底缘大弧是抛物线，缺 S 弯 | 图1/3 | 形态太对称，一眼"程序生成" |
| G4 | 无涡旋 curl | 图3 | 缺最有生命感的形态 |
| G5 | 褶皱幅度过小（0.030） | 图4 | 底缘太"干净"，缺竖直褶皱的波浪 |

| G8 | surge 是随机亮度脉冲，非传播波 | （视频） | 动态缺方向性 |

## 三、改进方案（aurora v8）

### A. 色彩还原（G1/G2）——收益最高、风险最低

**A1 带内四段色阶**（替换现 bodyCol 的两段 mix）：

```
altK = dd / (H * 1.6)  ∈ [0, 1]（带内归一化高度）
段0 底缘 (altK 0~0.08)：白绿 —— EMIT_GREEN × 1.5 向白偏（亮线自然白化）
段1 主体 (0.08~0.45)：黄绿 EMIT_GREEN
段2 上部 (0.45~0.85)：黄→橙红过渡（EMIT_RED 权重 0→0.7）
段3 带顶 (>0.85)：快速衰减到 0（已经由 body 的指数衰减保证）
```

**A2 亮芯白化增强**：whiteK 起点 0.75→0.55、上限 2.8→2.2、强度 0.8→0.9。
（回归测试 v7.1 断言"起点 ≥0.5"——0.55 仍合规。）

**A3 爆发品红层**：`act > 0.55` 时沿整条带（不只下缘）叠加品红：
```
magentaBand = act 的 smoothstep × body × (0.4 + 0.6 * rf)
emis += EMIT_PINK × magentaBand × MAG_ACT_GAIN(0.5)
```
颜色用 (1.0, 0.30, 0.55)（品红粉，图2 观感），不是 v7.1 下缘的蓝紫。

### B. 形态与动态（G3/G4/G5/G6/G8）——结构性

**B1 S 弯大弧**（替换/叠加抛物线）：
```
sCurve = S_AMP × sin(q.x × S_FREQ + wander2(ts, S_SWAY, sd) × TAU + fi × 2.0)
S_AMP = 0.14（跨屏 S 弯），S_FREQ = 1.1（波长 ≈ 0.9 屏宽）
yc += sCurve × span —— 与 ARC_K 抛物线叠加（抛物线保留但 ARC_K 1.35→0.9 减弱）
```

**B2 竖直褶皱增强**：WOB_AMP 0.030→0.075，且褶皱项改为**竖直条纹形状**
（沿带传播）：
```
foldWave = sin(q.x × (7.0 + 2.0×h2) − ts × 0.5 + fi × 2.1)
yc += wobA × foldWave（保留现有两项，幅度调大）
```
关键区分：v6 的"布料窗帘"是**整体大幅摇曳**（TILT 大 + WOB 大 + 弧线大弯）；
v8 的褶皱是**底缘局部小波浪 + 整体形态稳定**（TILT/ARC 不变，只加 WOB）。

**B3 射线解耦**（最重要的层次感改动）：
```
当前：bI = body × (rays + hero×0.35 + needles×0.55)  ← 射线被 body 锁死
改为：bI = body × (0.55 + 0.45×rays)                    ← 帘体基础（含弱射线）
     rayHalo = body × hero × HERO_GAIN(0.9) × actBoost  ← 英雄褶独立亮层
     rayBeam = rayGlow(q) × RAY_GAIN(1.6)               ← 独立射线层：
              rayGlow = presence × (0.5+0.5×rf)^2.2 × 上贯权重
              上贯权重 = exp(-dd/(H*3.5))（射线比帘体高 3.5 倍衰减高度）
```
射线扫动：STRIPE_DRIFT 0.9→1.6（更快），另加"射线相位沿高度倾斜"
（`sA/sB 的 y 项加 dd×TILT_PER_H(0.5)` → 射线上端相位偏移 = 视觉上的扫动）。

**B4 涌动改为传播波**：
```
surge = smoothstep(0.60, 0.85, vn(...)) →
surge = smoothstep(0.55, 0.90,
    sin(q.x × SURGE_WAVE_FREQ(1.8) − ts × SURGE_SPEED(0.9) + fi × 5.0) × 0.5 + 0.5)
```
一波亮度沿弧带从一端跑向另一端（速度恒定 0.9 rad/s），周期性出现。

**B5 涡旋 curl**（本轮**不做**，列为下轮）：实现成本高（坐标扭曲 + 选段 +
旋转场），且容易做假；先让 S 弯 + 褶皱 + 射线到位，涡旋值得单独一轮打磨。

### C. 光影与氛围（G7）

**C1 地平线低空辉光**（雪原/水面反光的通用化）：
```
groundGlow = EMIT_GREEN × exp(-pow((q.y − RIDGE_FAR_Y) × 6.0, 2.0))
           × auroraLum × 0.10
```
山脊上方一层贴地辉光，随极光总亮度起伏（比现有 upF/upN 上光覆盖更宽）。

**C2 星空微增**：三层星亮度 ×1.25（照片里星更明显；不动银河）。

### D. 技术路径

- **不需要**多 pass / 几何 shader / 新纹理——所有改动都在 `curtain()` 和
  main() 合成段，单 pass 直绘架构完全承载。
- 成本增量：色阶替换 0；S 弯 +1 sin；射线解耦 +2 pow；传播波 +1 sin；
  地面辉光 +1 exp。总 GPU 成本 +~3%，可忽略。
- 回归测试适配：aurora 三条断言（dneg 断崖 / body 含 dneg / whiteK ≥0.5）
  全部不受影响，无需改测试。

## 四、实施步骤与优先级

| 步骤 | 内容 | 优先级 | 预估 |
|------|------|--------|------|
| 1 | A1 四段色阶 + A2 白化增强 | P0 | 30min |
| 2 | B3 射线解耦 + 扫动 | P0 | 45min |
| 3 | B1 S 弯 + B2 褶皱增强 | P0 | 45min |
| 4 | A3 爆发品红 + B4 传播波 | P1 | 30min |
| 5 | C1 地面辉光 + C2 星空 | P1 | 20min |
| 6 | 量化验证（剖面 + 区域统计）| P0 | 30min |
| 7 | B5 涡旋 curl（下轮单独打磨） | P2 | 2~3h |

本轮实施 1~6；B5 列为下轮（需要单独调参避免"假涡旋"）。
